# Getting help

- **Usage questions:** read the [README](README.md) first, including the flag table and "What a
  run does". If that does not answer it, open an issue and add the `question` label.
- **Something is broken:** open a [bug report](https://github.com/ArtisanXL/create-monorepo/issues/new?template=bug_report.yml)
  with the command you ran, your Node and pnpm versions, and the output.
- **The guard blocked or allowed the wrong command:** use the
  [guard bypass form](https://github.com/ArtisanXL/create-monorepo/issues/new?template=guard_bypass.yml)
  (it covers false positives too).
- **Security vulnerabilities:** report privately, see [SECURITY.md](SECURITY.md).

This project is maintained by a single maintainer, so responses are best effort.
